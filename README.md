# Cognitive Biases & Heuristics in Security Decisions

An interactive class presentation on how cognitive biases shape security decisions. Four playable mini-games turn the ideas into choices the audience makes live:

- **Dual-Process Theory:** Fast Bot vs. Slow Bot phishing race
- **Optimism Bias:** a 12-month risk simulation
- **Present Bias:** the update snooze challenge
- **Security Fatigue:** prompt overload crisis

**Live demo:** https://zainabnawabi.github.io/cyber-biases-deck/

Use the arrow keys or the Next/Prev buttons to move through the slides. Click once on the page to enable sound.

## Built with

HTML, CSS, JavaScript and the Web Audio API, all in a single file with no external assets except web fonts.

Built with AI assistance (Claude) for code generation. Concept, content and design direction by Zainab Nawabi.
